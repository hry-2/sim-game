# 全柜联动是一个信箱：发信的机台只说"发生了什么"，收信的机台自己决定怎么办

聚宝盆和捕鱼达人已经共用一个[[币袋]]（ADR-0007）。现在要两台机器"互相知道对方发生了什么"：
捕鱼抓到鱼王 → 聚宝盆台上落一个奖品；聚宝盆开奖 → 捕鱼下一潮鱼王必来。

## 决定

一个 localStorage 键当信箱：

```
localStorage['arcade.link.v1'] = { v: 1, q: [ { to: 'pusher' | 'fish', kind: <string>, t: <ms> }, ... ] }
```

- **发信**只写"发生了什么"（`kind`：`king` / `dragon` / `jackpot` / `bingo`），不写"该给什么"。
  给什么、给多少，由收信的机台按自己的账决定——每台机器的账（ADR-0008 / ADR-0009）都只归它自己管。
- **收信**的机台只取 `to` 是自己的那几条，取完删掉。启动时、`storage` 事件（另一个标签页发的）、
  切回这个标签页时各收一次。
- 信箱最多留 20 条、7 天；过期的丢掉。

和币袋一样，两台机器各留一份十几行的 `linkSend` / `linkTake`（单文件游戏的代价），改字段两边一起改。

## 现在的信

| 发信 | kind | 收信 | 收到以后 |
|---|---|---|---|
| 捕鱼：抓到鱼王 | `king` | 聚宝盆 | 台上落一个奖品（台上已有就排队，最多 3 件）；每日任务"抓到鱼王"+1 |
| 捕鱼：抓到龙鱼 | `dragon` | 聚宝盆 | 撒一颗彩球（满 3 颗就排队）；每日任务"抓到龙鱼"+1 |
| 聚宝盆：电子屏开奖 | `jackpot` | 捕鱼 | 下一潮鱼王必来 |
| 聚宝盆：宾果全亮 | `bingo` | 捕鱼 | 下一潮鱼王必来 |

## 账

- 捕鱼那边：只改"鱼王什么时候来"，不改赔付和血量——ADR-0008 说过，出鱼的时机不碰每发的期望回收。
- 聚宝盆这边：送来的奖品 / 彩球还得被推下出币口才算钱，侧槽照样抽水。一条鱼王换来一个平均 ~25 币的奖品，
  而抓那条鱼王本身在捕鱼里要花几十到几百发——这笔"送的"是捕鱼那边花出去的币里漏出来的一点，
  不会让币袋通胀。排队上限 3 件，不会攒出一屏奖品。

## 代价

- 两个标签页同时读写信箱可能丢一封信（localStorage 没有事务）。丢一封"下一潮鱼王必来"无所谓，
  所以不加锁。
- 只有这两台机器认这个信箱。以后接进来的机台想收发，照着上面这张表加一行。
