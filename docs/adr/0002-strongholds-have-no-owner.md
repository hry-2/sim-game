# 据点不存归属：加固、床、储物箱、田一律写在镇子档里

静街里玩家钉的板、放的床和储物箱、开的田，**不记任何角色名**，
全部存在镇子档（`qs.town.<seed>`）里。谁下一个进到这栋房，这些东西就是谁的。

## 为什么刻意不照市井的做法

市井的做法是对的 —— 屋里原生家当的 `owner` 是个 getter，转发到 `HOMEOWNER[i]`，
人死了改一处 `HOMEOWNER` 全屋跟着换主。但它的**建造物**是另一套：
`owner` 存的是静态名字字符串，`die()` 里没有任何改写它的代码，
于是主人死后自建家当仍归死者名，除配偶以外谁都用不了
（`games/sim/index.html` 的 `BUILD.*.make()` 与 `die()`）。

市井是无限沙盒、死亡罕见，这个洞不致命。**静街是永久死亡 + 传承，每一局都会踩它**：
新角色会被自己上一局钉的板挡在门外。

## 被否掉的选项

存角色名再在死亡时改写归属（即"把市井那套 getter 补到建造物上"）。
它能工作，但它解决的是一个静街根本不需要的问题 ——
静街没有第二个会争夺据点的人（NPC 幸存者到 v0.2 才有），
存了归属就必须同时维护"空据点"那道额外闸门，而市井正是为此多写了一道。

## 后果

校验器钉一条：**镇子档的序列化结果里不许出现角色名**。
v0.2 加入 NPC 幸存者时，这条要重新算 —— 那时才真的有人跟你抢房子。
