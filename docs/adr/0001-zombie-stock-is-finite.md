# 僵尸是有限存量，镇子可以被清空

静街全镇的僵尸是一个固定存量（初值 320），只在街区之间迁移、被杀掉就没了；
补充只有两处：第 30/60 天各一次可预告的浪潮（+120），以及每天从镇外渗入的个位数。
**一个打得凶的玩家最终能把整座镇清空，而这被当成他挣来的一种结局，不是漏洞。**

## 为什么不按曲线刷怪

刷怪（同类作品的常规做法）会让"我清掉的那条街又满了"，
而清街是本作三条好处的来源：玩家的劳动有存量意义、噪音有战略价值
（把它们引到东边，西边就真的空了）、以及不会重犯市井 T26 那条"无限的水龙头会淹掉一切"。

## 被否掉的那个诱人选项

**浪潮规模跟已杀数挂钩**（杀得多来得多）看起来能一劳永逸地解决后期没对手，
但它是橡皮筋：它会把上面三条好处原样退回去，玩家很快能感觉到"清街是白干的"。
宁可接受后期变安静，并且把"安静"做成需要维护的东西（渗入）。

## 代价

后期的镇子会真的变空，噪音引擎在那时失去牙齿。这是明知故犯：
到那一步时玩家已经有了一座据点、一份长日志和一个可以挣的结局，
对手不再是主要压力来源。判断这条对不对，看探针第四张表的活动半径是否塌缩。
