# sim-game 策划文档 v0.1

> 本文是一次设计访谈的结论记录。每条决策都附了**理由**和**被否掉的选项**——
> 半年后回头看时，理由比结论更重要。
>
> 状态：核心结构已定，细节待展开。带 ⬜ 的是尚未决策的分支。

---

## 一、一句话定位

**你是一个村镇里的普通人。其他人不是布景——他们有自己的日程、目标和恩怨，
会和你抢资源，也会被你拉拢。**

参考坐标：星露谷（经营节奏）× 模拟人生（需求驱动）× 行会3（竞争与积累）。

与三者的关键差异：**NPC 是真正自主的，而且他们的动机对玩家可见**。
这是本项目唯一的技术护城河，所有设计都应该放大它，而不是绕开它。

---

## 二、核心假设（整个项目押在这一条上）

> **「看着一群有自己打算的人在你身边生活、竞争、结怨」本身就好玩。**

这条假设如果不成立，后面所有内容都是白做。
因此 MVP 的唯一任务是**尽快证伪或证实它**（见第七节）。

---

## 三、三条循环与它们的耦合

```
        ┌─────────────┐   金钱 → 送礼/请客   ┌─────────────┐
        │ A 经营生产   │ ──────────────────→ │ B 社交关系   │
        │ 原料→加工→钱 │ ←────────────────── │ 共处→关系→人脉│
        │ 反馈：分钟级  │   人脉 → 折扣/帮工   │ 反馈：天级    │
        └──────┬──────┘                     └──────┬──────┘
               │  ↑                                │  ↑
     金钱→买房/学费│  │技能→效率/配方        伴侣→成家 │  │身份→高阶NPC
               ↓  │                                ↓  │
              ┌───┴────────────────────────────────┴───┐
              │           C 人生进度                    │
              │   技能 → 身份 → 家庭    反馈：季/年级     │
              └────────────────────────────────────────┘

                  三者都在消耗同一种资源：★ 时间 ★
```

**六条耦合边全部存在**——这是三者能缝合的结构性原因，星露谷正是这张图。

但真正的引擎不是其中任何一条，而是**时间**。三条循环不是主次关系，
是**同一天里争夺时间的三个去处**。设计的核心工作是让这个争夺有张力。

**当前状态**：A 已跑通，B 有数值无用途（本次已解决，见决策 8），C 只有 skill 数字没有出口。

## 四、11 条决策

| # | 议题 | 决策 |
|---|---|---|
| 1 | 核心幻想 | 三者缝合，不做单一取向 |
| 2 | 主循环引擎 | **时间**是引擎，A/B/C 是一天里的时间段 |
| 3 | NPC 自主性 | 日程锚点 + 效用填空 + NPC 主动来找你 |
| 4 | 时间尺度 | 无限沙盒，无终局 |
| 5 | 重玩引擎 | 涌现叙事 > 随机事件 > 轻量建造 > 成长曲线 |
| 6 | 叙事燃料 | 记忆积怨（地基）+ 特质冲突（冲突源）+ 稀缺竞争（触发器） |
| 7 | 可读性 | 三层：事件流 > 头顶气泡 > 回忆档案 |
| 8 | 压力来源 | 「会失去」型：社会位置滑落 + NPC 是真竞争者 |
| 9 | 玩家不被碾压 | 规划优势（零成本）+ 雇人成长曲线 |
| 10 | 世界规模 | 核心圈 6~10 人 + 外围抽象；一村镇 5~8 场所 |
| 11 | 一天节奏 | 24 游戏时 ≈ 8 分钟；维持性占 30%，可支配时间**刻意不够用** |

### 展开：几条需要理由的

**决策 3 · 日程锚点 + 效用填空**

星露谷能做社交，是因为你知道周二下午 Harvey 在诊所。纯效用 AI 的 NPC
去哪取决于此刻谁最饿——**想送礼却找不到人**，社交循环直接断裂。

折中方案：NPC 有固定锚点（早上在家 / 白天在工作地 / 晚上在公共场所），
锚点之间的空隙由效用 AI 自由发挥。玩家能计划「晚饭后去酒馆」，
但具体谁在干嘛、心情如何仍然自主。《天国拯救》《骑砍》都是这个做法。

再加一条：**NPC 会主动来找玩家互动**，玩家不必总是追着人跑。

- 否决：完全固定日程（丢掉唯一护城河）
- 否决：完全自主 + 找人 UI（玩家要多跑路，挫败感强）

**决策 4 · 无限沙盒的代价**

无终局意味着没有「想看到结局」的拉力，必须有一台持续产生新东西的机器。
所有成功的无终局沙盒都有：模拟人生靠建造 + 关系组合爆炸，Rimworld 靠叙事生成器，
动森靠创作欲 + 现实日历，Factorio 靠无尽扩张。

**没有这台机器的沙盒，玩家平均两小时后弃坑。** 这是本决策带来的全部风险，
决策 5 是对它的回应。

**决策 5 · 排序的含义**

随机事件排在建造前面是省成本的选择，但要清楚它的性质：
随机事件是**往系统里灌新鲜感**，本身不产生新鲜感。它能撑住前 10 小时，
撑不住第 50 小时。作为第二优先没问题，不能指望它挑大梁。

**决策 6 · 现在的 AI 产生的是行为，不是故事**

「小满去砍树」是行为。行为变成故事需要三样东西，当前**一样都没有**：

| 要素 | 现状 | 缺什么 |
|---|---|---|
| 冲突 | ✖ | NPC 想要不兼容的东西时只是排队，没有摩擦表达 |
| 持久后果 | ✖ | 关系值会涨跌，但没有「因为那件事」——没有记忆 |
| 可读性 | ✖ | 玩家只能从打分面板推断，看不到事件本身 |

**记忆与积怨是分水岭**——没有持久后果，所有互动都是一次性的，玩家不会在意。
**性格特质是最便宜的冲突源**——加几行数据就能让两个 NPC 天然不对付。

**决策 8 · 为什么是「会失去」而不是「会死」**

「会死」型压力（需求崩溃、外部威胁）会随玩家变强而消失，后期变成纯操作。
「会失去」型压力永远有效：

- **社会位置会滑落**——不维护关系就退，别人挑拨 NPC 会转向
- **NPC 是真竞争者**——他们跑同一套效用 AI，同样砍树、做家具、卖钱、买房

第二条**几乎零额外成本**（NPC 早就在跑生产链了，只需让积累持久化并影响世界状态），
而且它把「NPC 抢资源是特色还是噪音」这个悬而未决的问题变成了答案：
**是特色，而且是压力的主要来源。**

**决策 9 · 一个必须解决的算术问题**

3 个 NPC 各自积累 vs 玩家 1 人——长期看玩家必输。这不是平衡微调，是结构性问题。

两条腿：

1. **规划优势（零成本）**——效用 AI 是**贪心**的，永远选当下最高分，
   不会为三步后的收益忍受眼前低分。玩家能囤货、等价、抢占位置。
   这个优势已经在代码里了，只需要做得可感知。
2. **从单干到雇人**——关系投资到位，NPC 愿为你工作，你从 1 人变 N 人。

第二条的价值远不止平衡：**它给了「关系」一个硬用途**，B 循环终于闭合。
成长曲线因此自然浮现：

```
自己干 → 请人帮忙(临时) → 雇长工(稳定) → 开作坊(多人协作)
```

每一步同时消费金钱和关系，把三条循环焊死。

**决策 11 · 取舍是锚点日程的副产品**

```
早上   大家在各自工作地      → 生产黄金时间（没人打扰）
下午   人流动，市场热闹       → 交易 / 偶遇
晚上   大家聚在酒馆          → 社交黄金时间
```

晚上是唯一能高效社交的窗口，但也正是能加班生产的时间。
**「今晚去酒馆维护关系，还是留在作坊多做两件家具」——这个取舍不需要额外设计。**
一个机制（锚点）同时解决了决策 3 和决策 11。

## 五、一天的时间预算

| 项目 | 游戏时 | 占比 |
|---|---|---|
| 睡觉 | 4~6 | ~20% |
| 吃饭 ×2 | 1.5 | 6% |
| 卫生 / 如厕 | 0.7 | 3% |
| **维持性小计** | **~7** | **~30%** |
| **可支配** | **~17** | **70%** |

设计目标：**让这 17 小时明显不够用**。稀缺才有取舍，
从容就只剩执行。

一天 ≈ 8 分钟现实时间（当前原型是 6 分钟，建议放慢；可在设置里让玩家调）。

> 注：精力需求**就是**体力条，不需要再加一条独立的行动点系统。

## 六、明确不做的

在核心假设被验证之前，以下一律不碰：

- 世代继承（状态管理成本高一个数量级，收益不明）
- 战斗系统
- 多村镇 / 可迁移（引出「玩家不在场时远处怎么模拟」的大坑）
- 生老病死
- 完整建造模式
- 联机

## 七、MVP：一周试玩

**判断标准只有一条：能不能验证核心假设。**

### 必须有的

| 项目 | 缺了会怎样 |
|---|---|
| 锚点日程 | 玩家找不到人，观察不成立 |
| 记忆与积怨 | 冲突没有因果，只是随机 |
| 事件流 | 故事发生了但玩家看不见 |
| NPC 持久积累 | 感觉不到「别人在往前跑」 |
| 6 个 NPC + 2~3 种性格特质 | 组合不够产生摩擦 |

### 不做

雇人、建造、随机事件、季节、成长解锁、更多场所、更多社交动作。
这些都是**验证之后**才值得投入的。

### 规模

一个村镇，跑通 **7 天**，玩家单次 40~60 分钟。

### 验证方法（比 MVP 内容更重要）

找 5 个人玩，玩完只问一个问题：

> **「说说这一周发生了什么？」**

**假设成立**——他们能讲出有人物有因果的故事：
> 「老莫一直抢我的工作台，后来我送礼给芜青让她帮我，
> 结果老莫和芜青吵起来了。」

**假设不成立**——他们说：
> 「就是看着小人走来走去，我在砍树卖钱。」

后者出现时**不要硬做涌现叙事**，转去做建造或成长曲线——那两条路更可靠，
只是没那么独特。

这个测试花一周，能省掉半年的方向错误。

## 八、风险清单

| 风险 | 等级 | 说明 | 缓解 |
|---|---|---|---|
| 核心假设不成立 | **高** | 涌现叙事对多数玩家可能只是噪音 | MVP 第七节的验证，尽早做 |
| 无终局导致留存差 | **高** | 沙盒没有拉力 | 决策 5 的四台机器；先验证第一台 |
| 涌现叙事读不懂 | 中 | 系统很深但玩家感知不到 | 决策 7 三层可读性，事件流优先 |
| 平衡失控 | 中 | NPC 竞争者会找到玩家想不到的套利 | 长时间无人值守跑测；已有冒烟测试基础 |
| 内容量不足 | 中 | 6~10 个 NPC 的组合迟早穿透 | 特质随机化 + 新 NPC 迁入 |
| 范围蔓延 | **高** | 三题材缝合天然容易失控 | 第六节的「不做」清单当硬约束 |

## 九、待决问题（下一轮）

- ⬜ **题材与年代**——中世纪？近代？架空？影响生产链、建筑、命名
- ⬜ **玩家能动性的边界**——能直接命令 NPC 吗？还是只能通过社交施加影响？
- ⬜ **成长解锁的具体形状**——技能树？配方解锁？身份阶层？
- ⬜ **建造模式的粒度**——只摆家具，还是能砌墙划房间？
- ⬜ **存档设计**——无终局沙盒的存档会持续膨胀，需要早想
- ⬜ **失败状态**——沙盒里到底会不会「输」？破产？被驱逐？
