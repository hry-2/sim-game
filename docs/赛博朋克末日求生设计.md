## 决策记录

这份设计是几轮取舍定下来的，留档备查：

| 议题 | 结论 | 理由 |
| --- | --- | --- |
| 改哪一层 | 题材 + 机制，不是换皮 | 要真正换核心循环 |
| 纳入哪些支柱 | ① 昼夜+生存值 ② 搜刮+制作 ③ 夜晚守据点 | 三根足够撑起「末日求生」 |

| 连夜奖励 | **要**：每夜 +10% 废钢，封顶 +50% | 给「再守一夜」一个经济动机，不是只有记录动机 |

| v1 中途存档 | 作废并提示 | 元进度在 `ns.prof`，不受影响，只丢一局中途存档 |

## 一句话

断电后的下城区。白天搜刮、黄昏回据点、夜晚守核心，无限夜刷生存记录。
饿、渴、辐射一直在掉；死了照常结算、回据点再来一趟——没有永久死亡，也没有通关。

## 核心循环

```
据点(开局准备：看委托/选起手) → 白天(100s) 在城区搜刮 → 黄昏(12s) 回据点补给/治疗/收工 → 夜晚(70s) 守核心 → 天亮 天数+1 → 无限
```

开局从据点出发：标题页只有「开始新游戏」和「选择存档」两个主动作。新游戏先进据点，
点「出发搜刮」才开局；「选择存档」列出全部存档槽（每局一个，互不覆盖，可删），点哪份读哪份。
结算屏「重新接入」也走据点；续档直接续上。

结束只有两种，**都没有胜利**：

1. **核心被毁** → 本趟结束，废钢 ×0.7 结算，回据点
2. **主动收工**（黄昏按键）→ 废钢 ×1.0 结算，记录更干净

## 状态机

`dawn → dusk → night → dawn …`

| phase | 时长 | 玩家 | 敌人 |
| --- | --- | --- | --- |
| `dawn` | 100s | 城区自由搜刮、打零星残敌 | 少量（密度 ×0.35） |
| `dusk` | 12s | 回据点制作/补给；可主动收工 | 不刷，残留清场 |
| `night` | 70s | 守中心核心，拦尸潮 | 大量，目标=核心 |
| 天亮 | — | 天数 +1，容器刷新，生存值延续 | 清场 |

周期性事件：
- 每 3 夜一次 **storm**：酸雨（核心+玩家持续掉血）/ 辐射昼（辐射涨速 ×3）/ 铁潮（精英翻倍）三选一轮转
- 每 4 夜 **换城区**：三张场地循环，危害换一种（复用现有换场逻辑）
- 每 5 夜 **夜末 BOSS**（复用 `bossOf()`）

## 生存值

字段 `hunger / thirst / rad`，0–100，存在 `G`（不跨局）。

| 值 | 起始 | 衰减 | 后果 |
| --- | --- | --- | --- |
| 饱食 | 100 | −0.35/s（约 2.8 天耗尽） | 0 → −2 HP/s |
| 水分 | 100 | −0.5/s（约 2 天耗尽） | 0 → −2 HP/s |
| 辐射 | 0 | 昼 +0.1/s、夜 +0.2/s；靠近熔渣/辐射区 ×3 | ≥60 视野轻微扭曲；≥100 −3 HP/s |

三条独立、可叠加（F=0 且 W=0 → −4 HP/s），提供持续的小压力。
恢复手段：食物 +30F / 水 +35W / 抗辐药 −30R。不随天数变严，压力恒定，难度来自尸潮。

## 夜晚守核心

复用 `updateEvac()` 的结构，`G.evac` → `G.core`：

- 核心 = 场地中心的柱子，`HP = 300 + day×60`，敌人碰到就掉血
- 敌人 AI：夜晚目标点改为核心；玩家进入仇恨半径（~90px）时转向玩家
  —— 这是最大的机制改动点，现有敌人一律追玩家
- 刷怪：`budget = round((16 + 11 × N^0.9) × DG.mass)`，无预算上限、四面来
- 守到天亮 / 核心归零结束；每 5 夜夜末出 BOSS

## 经济（已锁）

```
coreMul   = 核心失守 ? 0.7 : 1.0          // 主动收工 = 1.0
streakMul = min(1.5, 1 + 0.1 × 存活夜数)
bank      = floor(scrap × coreMul × streakMul)
```

- `bankRun()`（L4182）照常把废钢和里程碑存进档案，**元进度逻辑不动**
- 连夜奖励让「贪一夜」有经济动机；核心折损让「收工」有权衡，但不构成永久死亡
