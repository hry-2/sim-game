## 0 · 写法约定

1. **不写旁白**。所有设定从人嘴里、招牌上、广播里漏出来。玩家不知道"固件锁"是什么没关系，第三天自己会疼。
2. **一个委托 = 一个人 + 一个两难**。三个选项，每个都有人受益有人受损。没有"正确答案"，只有"你是谁"。
3. **任务结束多一句家里人的台词**。宁可少写一段过场，不可少这一句。
4. **灰掉的选项要留着**，写明条件。玩家看见自己错过了什么，二周目才有理由。
5. 台词短。港区的人说话不绕，一句话不超过两行。公司的人说话绕，那是他们的特征。
6. **主角性别玩家自选**，所有台词不带性别称呼。三种叫法就是三条线：港区叫"小九"，公司系统叫"用户 A-77120"，HR 和许维安叫全名"陈九"。带性别的称呼一律写成 `{哥|姐}` 由程序按玩家选择替换（穹顶旧同事的"陈{哥|姐}"、港区小辈的"九{哥|姐}"）。
7. **恋爱不写甜**。港区没有人有闲工夫甜。写的是两个倒计时的人互相借一点时间。
8. **恋爱对象对任何性别的主角都可追**，台词一字不改。这不是设定，是写法：不写"男人/女人怎样怎样"这种句子就行。
9. **分支走完要有显式的结尾**（`→ 某个锚点`），否则执行会漏进下一块。多个分支共用的尾巴要单独给一个锚点。
   `tools/script2json.js` 会把漏掉结尾的块全部报出来 —— 这类 bug 肉眼看不出来。
10. **`*如果 …：*` 的作用域到空行为止**。分支内部不空行，公共尾巴前面空一行。
11. **`*走位：<地图> · <提示>*`** 把控制权交给玩家：加载那张地图，走到目标点按 `E`，
    再从这一行往下接着说。读和玩因此能在同一场戏里交替，不用把一场戏拆成两场。

**对话数据格式**（T8 要吃的）：

```
{ id, who, text, opts: [ { text, need, set, goto } ] }
need：条件表达式，例："rep.street>=20" / "flag.saved_xiaolu" / "love.alu>=2" / "money>=800"
set：写标志位或改数值，例："flag.told_truth=1; rep.gang+=5; love.linke+=1"
```

正文里用这个记法：

```
> 选项文字                          【need】 → set → goto
```

## 1 · 世界圣经（只给写的人看，玩家永远看不到这一节）

**沪港**。一座三十年前填海造出来的城市。填海是三家公司合资的，所以城市从第一天起就是私产。

- **上城**：三个穹顶，各归一家公司。空气过滤、恒温、有草坪。进出要固件授权。
- **下城 / 旧港区**：填海前的老渡口和码头，公司把不要的人和不要的东西都留在这里。潮湿，霓虹，永远在修路。玩家住这里。
- **新陆**：还在填的那一片，工地、集装箱、走私船靠岸的地方。终局在这里。

**三家公司**：

| 公司 | 干什么 | 在剧情里的位置 |
|---|---|---|
| **环宇** | 义体制造商，固件锁的持有者 | 所有人的债主。永久解锁要打的最后一台服务器在它的穹顶 |
| **明烛** | 数据与安保。城市的摄像头、门禁、私人保安全是它的 | 主角的前雇主。公司线的甲方 |
| **澜海** | 填海、港口、物流 | 帮派的对手，也是帮派的货源。码头之夜的交易方 |

**固件锁**。所有义体每三十天要从环宇拉一次固件签名，否则降级运行：先是义眼雪花、义肢延迟，两周后瘫痪。签名是订阅制，钱从公司工资里代扣。**被裁员就等于被拔了氧气管**，有 90 天的"离职宽限期"，宽限期这个词是明烛 HR 的发明。

**苗子计划**。明烛每年从港区挑十几个十七八岁的孩子进穹顶做安保，包吃住、配义体、签十年合同。义体是"预支的"，合同做满归你，做不满就是债。港区人管这叫"卖身上穹顶"，但每年报名的排到巷子口。**主角是第九期**，"九"不是名字，是号。

港区有三种活法：
1. 找到新雇主，接着代扣（公司线）
2. 买帮派的破解固件，便宜、能用、随机出故障，用三次坏一次（帮派线）
3. 相信老网客说的：锁是可以永久拆掉的，环宇只是不让你知道（网客线）

**主角为什么重要**：三处公司配的高等级义体（右臂、双眼、脊柱），宽限期一过瘫得最快；七年里摸熟了明烛所有旧门禁；去年在内审组查到的最后一个人是许维安。三方都想要前两样，第三样只有许维安知道。

## 2 · 人物表

### 主角

**陈九**（小九 / 陈九 / 用户 A-77120），25 岁，性别玩家选。港区长大，桂记面馆后厨吃到十八岁。明烛苗子计划第九期，18 岁进穹顶，站门四年，后三年调进内审组。合同还有三年才满，义体的债没还完就被裁了——**裁员不只是失业，是三处义体一起变成欠款**。被裁的理由是"岗位结构优化"。真实原因在公司线第三个任务里揭开：内审时查到许维安。

性格底色：话少、守规矩、对人客气、对自己狠，在穹顶学会了绕着说话但一回港区就改不过来。这是**玩家可以背叛的底色**——选项里永远有一个"陈九不会这么做"的选项，选了就是玩家在改写。

25 岁而不是 41 岁的区别，写的时候要记住：**这个人还没有输过**。第一稿的陈九是认命的人在挣最后一口气；第二稿的陈九是第一次发现规矩不保护守规矩的人。台词要更冲、更快、更容易被人激。

### 三个中间人

**许维安**（许总），明烛安保总监，50 岁，说话从不把主语说全。**是他七年前在港区面试时挑中了陈九**，一路带进内审组——港区人都知道许总是小九的"恩人"。裁掉陈九不是因为不需要，是因为陈九快查到他。现在又找回陈九，是因为需要一个不在公司名册上的人干活。他给的活越来越脏，最后一个活的目标是林可。

**蔡六指**（六指），港区"潮帮"的二当家，36 岁，左手真的只有五根手指，六指是反着叫的。讲义气，也真的会卖你。他看着陈九长大，一直觉得苗子计划是把港区的孩子送去当狗；陈九被裁回来，他一半是要门禁密码，一半是想证明自己当年说对了。

**老鲸**（周鲸），隐居的老网客，62 岁，住在港区一台报废的疏浚船里。三十年前参与写过固件锁的第一版，因此知道它有后门，也因此在通缉名单上待了二十年。他不劝人，只给你看东西。他会死在网客线的倒数第二个任务里，死之前把密钥给你。

## 3 · 三条主线大纲

时间轴以固件宽限期计，第 1 天 = 裁员日，第 90 天 = 瘫痪。

### 序章（第 1~3 天）

**P0 · 裁员日**（全文见第 5 节）。明烛穹顶 → 回港区 → 桂记面馆。教移动、对话、第一次看见倒计时。

**P1 · 三封消息**（第 3 天）。阿鲈那里同时收到三个人的口信。玩家先见谁不影响后面，但**见的顺序决定三个中间人的第一句话**。

### 前 30 天：三条线并行，各两个任务

| 线 | 任务 | 一句话 | 两难 |
|---|---|---|---|
| 公司 | **M1 · 旧钥匙**（全文见第 6 节） | 许维安要你用旧门禁进一间明烛的档案室，取一块硬盘 | 硬盘里有你自己被裁的原因。看还是不看 |

### 第 30 天 · 码头之夜 ★不可回避

澜海的一艘船靠岸，船上一批正版固件签名密钥。明烛派人来查货（许维安），潮帮来抢货（六指），老鲸要你趁乱把密钥拷一份。三方都给你派了任务，**你只能完成一方的**。当晚的选择锁定主线。

- 帮明烛：货被查扣，六指的人死两个，小陆（如果 G1 里你护了他）在其中
- 帮潮帮：货被抢，许维安记住你的脸，林可在公司里替你挡了一次
- 帮老鲸：货谁都没拿到，密钥在你手上，两边都以为是对方干的——这是唯一一条暂时不树敌的路，也是后面最难的路

**恋爱线的第三拍全部发生在这一夜之后**（见第 4 节）。

### 第 31~75 天：单线

**公司线** M3~M6：
- M3 · 复职：许维安给你临时工牌，账户恢复，倒计时暂停。你回穹顶，发现你的桌子被拆成了储物间，林可的桌子还在

**网客线** N3~N6：
- N3 · 澜海：打三家服务器的第一家。青蛉在你眼睛里给你指路
- N4 · 明烛：第二家，是你的老东家。林可从里面开门
- N5 · 鲸落：老鲸暴露，明烛的人打到船上。你赶到时他已经不行了。**青蛉也在船上，救他还是先拿密钥**
- N6 · 终局前夜：环宇穹顶。全城义体人的固件锁在一台机器上

## 4 · 恋爱线

### 规则

- **四个人，两女两男**，对任何性别的主角都可追。台词一字不改。
- **不是数值条，是三个选择**。每人一个 `love.X` 计数，0~3，只在三个关键处 +1。没有送礼加好感这种事，港区没人有闲钱。
- **四拍**：相识（在主线里自动发生）→ 靠近（一个专属支线）→ 抉择（码头之夜后，这个人被主线卷进来）→ 结局（改写该线结局的一幅画面）。
- **只能和一个人走到第四拍**。走到第三拍的其他人，在抉择那一夜会退出，各带一句台词。不写争风吃醋，写的是"你选了一条路，我不在那条路上"。
- **恋爱不给数值奖励**。给的是：一个人的立场、一处能过夜的地方、一句结局里的话。
- **恋爱可以失败**。第三拍选错，这个人不会死，但会从街坊表里换一句话，然后再不提。

### 四个人

#### 林可 · 女 · 27 · 公司线

穹顶出生，明烛内审组，陈九三年的搭档。她做事比陈九更守规矩，也更早看出规矩是谁写的。她是**唯一一个知道陈九为什么被裁的人**，因为那份报告是两个人一起写的，最后只有一个人的名字被优化了。

| 拍 | 在哪 | 内容 | love.linke |
|---|---|---|---|
| 相识 | P0 场景 2 | 保安转达："林{哥|姐}让我跟您说一句：她没签。"（flag.walk_alone 时才有） | — |
| 靠近 | 支线 S5「合影」（第 9 节） | 她来港区要那张合影，背面有许维安私人档案柜的密码。给不给 | 给 → +1 |
| 抉择 | 码头之夜后 | 公司线：M4 里你查到她。**帮派线**：G2 里你留没留痕迹让她背锅。**网客线**：N4 她给你开门 | 保她 → +1 |
| 抉择 II | M5 / G5 / N5 | 她主动来港区，问你一句："你要是没进苗子计划，现在在干什么。" 三个回答，一个 +1 | 答"在桂姐店里擀面" → +1 |
| 结局 | 第 10 节 | 见 E1 / E2 / E5 的恋爱变体 | ≥3 |

**她的退出台词**（第三拍时你选了别人）：「内审组的规矩，两个人签的报告，一个人不能改。你改了。」

#### 阿鲈 · 男 · 29 · 帮派线

港区长大，和六指是一条巷子的发小，六指进了帮他没进。潮声酒吧是他爹留下的，三年前抵押给六指换了他爹的固件钱，他爹还是没撑过去。**酒吧现在是六指的，他是给六指打工的**，全港区只有他知道，因为他不说。

|---|---|---|---|
