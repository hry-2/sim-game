# 六爻 · 金钱卦

三枚铜钱掷六次成一卦，读《周易》的卦辞、动爻与变卦。单文件、零运行时依赖、不联网。

打开 `index.html` 即可玩，或访问 `http://localhost:5173/games/liuy/`。

## 玩法

1. （可选）写下所问之事。**它只作记录，不参与起卦**——卦随缘起，不随问变。
2. 逐爻掷钱，或点「自动起卦」。每次三枚铜钱落定，自下而上成一爻：

   | 三钱之和 | 名称 | 阴阳 | 动/静 | 画法 |
   | --- | --- | --- | --- | --- |
   | 九（三背） | 老阳 | 阳 | 动爻 | 实线加 ○ |
   | 八（两背一字） | 少阴 | 阴 | 静爻 | 断线 |
   | 七（一背两字） | 少阳 | 阳 | 静爻 | 实线 |
   | 六（三字） | 老阴 | 阴 | 动爻 | 断线加 × |

3. 六爻成**本卦**。老阴、老阳翻转阴阳后得**变卦**；六爻皆静则无变卦。
4. 解卦页分两层：**白话**（绿卡）用大白话讲这卦讲什么、每条动爻在说什么；
   **经文**（米黄卡）是《周易》原文，一字未改。卦辞断大势，动爻的爻辞察其变处，
   变卦示其去向。动爻多时以爻辞为主。

乾卦六爻皆老阳出「用九」，坤卦六爻皆老阴出「用六」。

## 数据

- 六十四卦（文王序）的卦名、上下卦、卦辞、六爻爻辞全部内置，取自通行本《周易》原文。
- `PLAIN` 是独立的白话层：64 段卦意 + 384 句爻话，与经文分栏、不混排、不改写经文。
  改经文时不要碰它，改白话时也不要碰经文。
- **旁卦**由本卦六爻位串推导（`deriveHexes`）：互卦取 [2,3,4] 为下、[3,4,5] 为上；
  错卦六爻全反；综卦六爻倒转。三者只作参考，不另起卦，主判仍是本卦/动爻/变卦。
  解卦页、复制文本、复制给 AI、卦典详情四处均列出。
- 八卦以自下而上的三爻位串表示（1 阳 / 0 阴），上下卦拼成六位串后查表定位卦序。
  已校验：64 卦一一对应、六爻齐全、位串往返无歧义。
- 卜册存 `localStorage` 的 `liuy.records.v1`，最近八卦，只在本机，点按可复制卦文；另有「清册」按钮。
- **卦典**：点顶栏「卦典 · 64」弹出全 64 卦，可按卦名 / 卦辞 / 白话 / 序号搜索，点任一卦看它的
  卦象、卦意、经文和六爻白话——不必掷钱就能查。
- **六爻一览**：解卦页列出每一爻的爻题、少阴/少阳/老阴/老阳、几字几背、动/静；点任一爻展开看
  它的白话和「为什么动」。同一份清单也进「复制卦文 / 复制给 AI」。
- **掷钱音效**：WebAudio 实时合成的三声铜钱脆响，零资源、离线可用；「声 · 开/关」开关存 `liuy.sound.v1`。

## 用词与设计

见根目录 [`CONTEXT.md`](../../CONTEXT.md) 的「六爻」一节。几条定死的规矩：

- **掷钱是真 3D 翻滚**：铜钱有厚度（24 段圆周侧面），多轴旋转 + 抛物线回弹 + 地面投影 +
  随转动变化的打光与动态模糊。全部用 CSS 3D 与 `requestAnimationFrame` 手写，零依赖、离线可用；
  `prefers-reduced-motion` 下直接落定，不做动画。
  两面一眼可分：**字面**是暗金底 + 四个朱红大字，**背面**是银白「光背」+ 浮雕环纹，
  落定后每枚钱下方还有「字 · 阴 / 背 · 阳」小标签。注意 `.coin3d` 上不能用
  `will-change: filter`，否则 Chromium 会把 3D 场景压平、背面永远不显示。
- **所问之事不是随机种子**。写不写、写什么，都不改变掷钱结果——它只是卜册里的一行备注。
- **卦辞爻辞是经文，不改写、不「翻译」成白话断语**。要解读的是人，不是程序。
  白话另起一层、标明是今人解读，只帮人看懂经文，绝不冒充经文。
- **没有吉凶评分、没有分数、没有成就**。占卜是照见心绪的一面镜子，不是替人决断的神谕。
