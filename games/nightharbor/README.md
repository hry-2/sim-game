# 夜港 · NIGHT HARBOR（原型）

> 游戏合集里的一款，返回 [游戏柜](../../README.md)。
> 策划见 [夜港策划拆解](../../docs/夜港策划拆解.md)，剧本见 [夜港剧本](../../docs/夜港剧本.md)。

赛博朋克俯视角潜入 / 枪战 + 剧情。单文件、零依赖，双击 `index.html` 就能玩。

现在能玩到的是：**序章全场 + 三支线各第一个任务 + 阿鲈的第二拍**，带人物立绘、九个场景背景、两段可走的路，
关卡还能用 `V` 在俯视角和第一人称之间切，
其中 M1「旧钥匙」是完整的一趟（接活对话 → 潜入关卡 → 摸到硬盘 → 撤离 → 结算 → 交活 → 次日街坊）。

## 剧本是数据，不是代码

游戏里**没有一句写死的台词**，也没有一行"如果玩家选了 A 就说 B"。

```
docs/夜港剧本.md  ──node tools/script2json.js --embed──▶  games/nightharbor/index.html
   （写手改这个）                                              （SCRIPT 常量）
```

```bash
npm run script          # 解析剧本 + 嵌回游戏
node tools/script2json.js   # 只看统计和未解析项，不写文件
```

当前：**5 支任务 / 17 场 / 385 步 / 68 个选项 / 18 条街坊台词**，零条未解析。

分工是刻意的：

| 谁负责 | 什么 | 多久变一次 |
| --- | --- | --- |
| 剧本 markdown | 对白、选项、条件、标志位、跳转、旁白、屏显 | 天天变 |
| 游戏里的 `SCENE` / `MISSION` | 哪一场接哪一场、哪一场加载哪张地图、目标文字 | 很少变 |

解析器认的就是剧本现在的写法，不用给 markdown 加标记：

```
## 5 · P0 · 裁员日        一支任务
### 场景 1：xxx           一场（"→ 场景 2" 按序号找）
*斜体*                    旁白（以"关卡："开头的是设计注记，玩家看不到）
*如果 flag.x：*           往下的台词挂条件，到空行为止；*如果不是：* 取反
**谁**（小注）：台词       对白
**1a**                    跳转锚点
```…```                   屏显（终端 / 义眼里的字）
> 选项 【条件】 → 赋值 → 去哪
```

解析器还带一条 lint：**分支走完没有显式结尾**（会漏进下一块）会被报出来。
这类 bug 肉眼看不出来，第一次跑就抓到三处。

## 画面：立绘 + 场景

第一版把剧本接完就直接给人玩，结果一句话说到底：**全是字，没有画面**。
说话的人没有脸，背景只是一层渐变加雨，玩家开局要读一百多句话才碰到第一个关卡。
这是把顺序做反了 —— 策划里自己写着「剧情是给它加重量，不是补救它」。

补上的两样：

**人物立绘**（[tools/portrait_gen.js](../../tools/portrait_gen.js)）。19 个人，48×56 逐像素画，
放大 4 倍到 192×224 排成一张横图，游戏里用 `background-position` 切。部件化：
脸型 / 发型 / 眼睛（含义眼）/ 嘴 / 领口 / 赛博件（颈后接口、太阳穴钢板、面罩、疤）。
说话的人一换，脸就跟着换；闸机、广播这种没有脸的就不显示。
主角两个性别各一张，剩下的台词一字不改。

```bash
npm run portraits    # = node tools/portrait_gen.js --embed
```

**场景背景**。九个地点各画一幅，都是程序化的，跟着 `where` 字符串选：

| 地点 | 画了什么 | 在动的东西 |
| --- | --- | --- |
| 穹顶 · 会议室 B | 天花板灯槽、墙上的大屏、长桌、椅背 | 屏上的进度条 |
| 穹顶 · 一号门 | 玻璃墙外那片买来的草坪、两台闸机 | 你那台闸机的黄灯在闪 |
| 轨道车 | 车窗、扶手、座椅 | 窗外掠过的楼与雨 |
| 桂记面馆 | 「桂记」招牌、三只吊灯、灶台、两只碗 | 锅上的蒸汽、灯的抖 |
| 潮声酒吧 | 酒瓶架、吧台、擦干净的杯子、墙上比周围新的那一块 | 招牌在闪 |
| 后巷 / 巷子 | 砖墙、落水管、垃圾箱、一盏灯 | 灯的接触不良、雨、积水 |
| 旧渡口（港区街上） | 霓虹招牌、亮着灯的楼、远处的穹顶 | 雨、积水的反光 |
| 疏浚船 | 一整墙滚字的显示器、折叠床、一只保温杯、船体的锈 | 十八块屏各自在滚 |
| 穹顶外围 · 餐厅 | 包厢、窗外穹顶的光、低垂的灯、两副筷子 | 灯的光晕 |

**穹顶里不下雨，港区一直在下**。这不是省事，这是穹顶存在的意义。

## 走位段：让读和玩交替

有了脸和场景之后，序章的另一个问题才看得清：**开局五分钟只有"读"，没有"玩"。**
剧本里第二场（一号门）本来就写着「教学：WASD 移动。走到闸机前」，
第一版把它当设计注记跳过了。

现在它是剧本里的一行，而且是可执行的一行：

```
*走位：gate · 抱着箱子走到闸机前，按 E 交工牌*
```

解析器把这一行变成一个 `walk` 步。游戏读到它就交出控制权：加载那张地图、
让你自己走过去、按 `E`，然后**从这一行往下接着说**，走之前说过的话还留在上面 ——
是同一场戏被打断，不是两场戏。

好处是写手能把可玩的段落插在任何一句话之间，不用为了一小截走路把一场戏拆成两场。
序章因此变成：读（会议室）→ 走（一号门）→ 读（轨道车 / 面馆 / 酒吧）。
G1 的护送也用了同一个机制：和小陆聊完，自己穿过三条巷子。

**地图不再只有一张。** 每张带自己的调色板，一眼就知道在哪：

| 地图 | 用在哪 | 调色板 |
| --- | --- | --- |
| `warehouse` | M1 安保部老楼 / N1 信号塔工地 | 工业：冷灰蓝 + 木箱的暖棕 |
| `gate` | 序章 · 明烛穹顶一号门 | 穹顶：干净、偏亮、玻璃幕墙外是草坪 |
| `alley` | G1 · 通往十七栋的三条巷子 | 港区：脏、暗、暖 |

走位段不是任务：没有敌人、不能开枪、没有结算屏，手里拿的也不是枪
（一号门那一段是纸箱）。目标点上有个跳动的箭头，靠近了显示 `[E]`。

> 载入地图时会自己从起点 BFS 走一遍到目标点，走不通就在控制台报错 ——
> 布局改一改就可能把路封死，这种错肉眼看地图字符串是看不出来的。

## 第一人称：`V` 键随时切

俯视角和第一人称跑的是**同一份模拟**，切视角只换渲染和输入映射。
同一关能两种视角各打一遍，直接比。

能走这条路是因为**游戏本来存的就是一张字符网格**（`#` 墙 / `c` 掩体 / `g` 玻璃 /
`D` 门），那正好是光线投射渲染器的输入格式。Canvas 2D 逐列投射，
不需要 WebGL、不需要模型、不需要任何依赖，仍然是单文件。

三条规则在两种视角下必须一致，不能因为换了视角就变：

| 瓦片 | 规则 | 第一人称怎么画 |
| --- | --- | --- |
| 墙 | 挡视线挡子弹 | 全高，光线到此为止 |
| 掩体 | 挡子弹不挡视线 | **半高的矮墙** —— 你能看过去，打不过去 |
| 玻璃 | 挡子弹不挡视线 | 半透明，光线穿过去继续走，后面的东西透出来 |
| 门 | 关着才挡 | 关着是墙，开着是洞 |

墙面有装饰（竖管 / 亮窗 / 霓虹招牌 / 通风口 / 污渍），按格子和朝向做确定性哈希。
第一人称最怕四面空墙，这一层不做的话，同一张图在第一人称下就是个空盒子。

### 潜行的可读性怎么补回来

俯视角的潜行能玩，全靠视锥画在地上。第一人称看不见背后，这个赌注会当场塌掉。
补偿是两样，都在设定里本来就有：

**义眼扫描**（`Q`）。3 秒透墙看见所有人和他们的朝向，之后 8 秒冷却，
冷却期间你就是瞎的。主角装的就是环宇 V4 定制义眼，用它看东西天经地义。

**雷达**（右下角）。画视锥，颜色和俯视角同一套 —— 黄=未察觉、橙=搜索、红=交火，
学过一次就不用再学。

**守卫有三个朝向**：正面（看着你）、侧面、背面（看不见脸、颈后接口亮着、背着包）。
这不是装饰，是玩法：第一人称如果看不出他朝哪边，背后处决就没法玩。
背对你而且够近，准星下面会出现 `[E] 处决`。

### 键位（第一人称下）

| 键 | 作用 |
| --- | --- |
| `W` `S` | 前进 / 后退 |
| `A` `D` | 左右侧移 |
| 鼠标 | 转身（先点一下画面锁指针）；`←` `→` 是键盘的备用转身 |
| `Q` | 义眼扫描 |
| `V` | 切回俯视角 |
| 其余 | 和俯视角一样：左键开火、`Ctrl` 蹲伏、`空格` 冲刺、`E` 处决 / 读取 / 撤离 |

### 这一版还没有的

- **没有俯仰**（看不了上下）。这张图是给俯视角设计的，墙都是一格高，没有立体结构
- **敌人是广告牌**，三个朝向，没有行走动画
- **对话和场景那一套没动**，还是 2D 的立绘加背景 —— 第一人称只影响关卡里
- 关卡地图只有一张，而且它的布局是按俯视角的可读性设计的。
  真要往第一人称走，关卡得重新设计：更窄的走廊、更多竖直方向的东西、更少的大开间

## 全局状态

所有系统只读写一个 `ST` 对象：天数、固件宽限期、欠款、现金、标志位、
三条声望、四条恋爱线。对话的条件、任务结算、街坊台词、结局判定全看它。存档就是存它。

条件求值不用 `eval`，只支持剧本实际用到的语法：`flag.x`、`rep.corp>=5`、
`love.alu>=2`、`money>=600`、`!(...)`、`||`、`&&`。认不出来的条件默认放行并记进
`UNKNOWN`（宁可多给一个选项，也别把玩家卡住）。

## 操作

| 键位 | 作用 |
| --- | --- |
| `空格` / 点一下 | 对话继续（打字机没打完就一次打完） |
| `1` `2` `3` `4` | 选项。**灰掉的选项也显示** —— 你得看见自己做不到什么 |
| `W A S D` | 关卡里 / 走位段移动（跑步有 2 格噪音） |
| 鼠标 / 左键 | 瞄准 / 开火（9 格内都听得见） |
| `Ctrl` / `C` | 蹲伏：移速一半、不出噪音、敌人视距 -30% |
| `空格` | 相位冲刺，冲刺中无敌 |
| `E` | 从背后处决 / 读取目标（按住 2 秒）/ 撤离 / 走位段到点了继续 |

## 已实现

**T1~T3 关卡**：墙 / 掩体（挡子弹不挡视线）/ 可打碎的玻璃 / 自动门 / 暗房间；
敌人 ±55° 视锥画在地上，未察觉 → 搜索（8 秒，呼叫同屋）→ 战斗（互相通报，
3 秒没人看见你就丢失目标）；噪音、尸体被发现、背后处决。

**T7 任务结构**：接活 → 关卡 → 关卡内触发对话 → 撤离 → 结算屏（耗时 / 击杀 /
被发现 + 两个可选目标）→ 交活。

**T8 对话与标志位**：打字机、条件选项、`{哥|姐}` 按玩家性别替换、屏显、
条件旁白分支、次日街坊表。

**次日街坊**就是剧本每场末尾那张表。同一个任务，做法不同第二天听到的话不同：

| 你干了什么 | 第二天在面馆听到 |
| --- | --- |
| 看了硬盘、没杀人 | 桂姐 + 豆包「你眼睛怎么红的？」+ 林可的消息「你去了老楼。」 |
| 没看硬盘、杀了两个 | 桂姐 + 老韩「听说老楼昨晚死了两个外包的。」 |
