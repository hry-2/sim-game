# NEON SCRAPLINE

赛博朋克像素俯视角生存射击 · 纯前端单文件 · 无构建 · 无依赖

本目录的 `index.html` 一个文件就是完整游戏（HTML + CSS + Canvas 2D + WebAudio 合成音效，零外部资源，仅可选加载 Google Fonts）。

> 游戏合集里的一款，返回 [游戏柜](../../README.md)。

## 运行 / 部署

双击 `index.html` 即可。仓库根目录本身就是可发布的静态站点，
开启 GitHub Pages（`main` / `/(root)`）后本作在 `/games/neon-scrapline/`，
详见[根目录说明](../../README.md#部署到-github-pages)。

单独拿出去用也没问题——这一个文件就是完整游戏，没有任何外部依赖。

| --- | --- |

## 玩法结构

- **标题页有一份「怎么玩」**：从头讲清楚这游戏怎么玩，说人话、数字从代码里读、操作按设备只给一套，末尾一张「卡住了看哪里」速查表。
- **一局 30 波**，打穿第 30 波撤离上货梯 —— 有终点，曲线才画得出来。每十波加一层新机制。
- **撤离战**：打完第 30 波不直接结算，货梯停到场地中间（避开熔渣和冷凝罐），**站上去守住 40 秒**才算撤离成功。
  站在上面才走进度，下来只是停、不倒退；敌人没有预算、从四面不停地来，最后 10 秒场上上限拉满。
  HUD 的波次标签换成 `EVAC`，数字是还剩几秒；货梯不在屏幕里时边上有箭头指过去。
- **中途存档**：每一波开打前自动存一份（`localStorage['ns.run']`），关掉再开，标题页有「继续 · 第 N 波」。
  连三条随机流的位置一起存，所以续上之后摇出的修饰、发的牌跟没断过一样；打到一半关掉的那一波从头再打。
  死了、撤离、放弃都会清掉存档；有存档时「新开一局」要按两次。昨天的每日局存档不给续。
- **存档退出**：暂停里「继续 / 存档退出 / 放弃这局」三个键，底下写着各自会怎样。存档退出回标题页、不结算、存档留着：
  波与波之间（商店、休息）退会现存一份（刚买的也算），打到一半退用这一波开打前那份，选路开着时用摆路之前那份（不然续上会摇出另两条路）；
  第 1 波还没打完时没有存档，要按两下才退。
- **波次制**：清空后进入补给间隙，每 5 波一场 BOSS，三种轮着来，各自要换一套打法；每个掉到一半血都换形态。
- **打完 BOSS 选路**：第 5 / 10 / 15 / 20 / 25 波打完先停下来选一条路 —— 去另外两张场地中的哪一张，接下来五波怎么打。
  一条**平路**照常；一条**险路**在敌人身上加一样、在你身上翻一样：精锐（精英翻倍 / 废钢翻倍）、人潮（同屏多三成 / 经验 ×1.4）、重甲（敌血 +25% / 零件翻倍）。
  两条路用刷怪流摇，每日局大家一样、续上存档也一样；撤离战不吃路线。探针一律走险路时平均少走约 4 波、废钢多不少 —— 是个真取舍。
- **三张场地**，各带自己的地形危害：传送带推着所有人走、熔渣池站上去就烧、冷凝罐打爆炸一片 —— 都对敌人同样生效。
- **钉枪手只在屏幕里开枪**：画面只有 320×180，竖着上下各看得见 90px，它原来站在 220px 外 —— 探针量过八成九的蓄力在屏幕外起手，
  玩家只看见一条从边上扎进来的线。现在它沿自己的方向站在画面里（横向仍然远），看不见就不起手。
  机器人因此平均多走了几波（它本来就不会躲线，钉枪手是它的头号死因），人手上的难度变化应该小得多。
- **护盾过热也停自愈**：加时 12 秒还没清完，剩下的护盾、殉爆、呼叫、中继原本就会失效，现在自愈也停 ——
  探针撞见过一屏十只自愈精英回血比打得快，加时 386 秒收不掉。
- **敌人 11 种**（不算 BOSS），其中 6 种逼你改打法：铁闸正面挡伤、爆囊靠近就炸、中继给同伴加盾、裂解体死了裂成两只、钉枪手远处蓄力打直线、拖曳者甩钩把你拽过去。
  第一次遇见都会给一句该怎么应对，之后在暂停界面的图鉴里随时能翻回来。
- **精英与波次修饰**：精英带一圈标记、掉双倍，各带一个词缀（自愈 / 护盾 / 殉爆 / 呼叫），环的颜色就是身份；
  每隔几波摇一个波次修饰（七种），用敌人组合换难度，不是把血条拉长。
- **武器十七把**，分三条路（远程 8 / 近战 3 / 炼金 6）。**武器栏 6 格，类别随便配，同一把能带两把，带着的全部同时自动开火**（土豆兄弟那样），开局一把，其余从升级卡里拿，满 6 把后换装卡不再发。改的是打法不是数值，详见下面一节。
- **合成**：同名、同品阶的两把能合成高一阶的一把（Ⅰ→Ⅱ→Ⅲ→Ⅳ，伤害 ×1 / ×1.6 / ×2.4 / ×3.5），空出一格。
  能合的那一格会呼吸着亮，战斗里随时点它（键盘 `C`、手柄 `Y`）就合，**不自动合**。
  两把 Ⅰ 一起打是 ×2，合成的 Ⅱ 只有 ×1.6 —— 合不合看你要伤害还是要格子。合完空出的格子会让换装卡重新进卡池。
  能合的格子是按钮，合不了的不接指针：手机上手指按在武器栏上照样是摇杆。
- **伤害数字**：打中时冒数字（3×5 像素字，画布上写真字是糊的），同一只 0.15 秒内的并成一个往上加；暴击大一号金色，自己挨打红色。「观感」里能关。
- **波末自动回收**：一波打完，地上的经验、废钢、零件、血包自动收进来（增益留在地上，别在休息时白白吃掉）。
- **每波都开商店**：上面是**货架**四格 —— 被动道具（16 种，大多带代价，每样一局最多 3 份、已有几份贵几成）和武器混着摆，
  能**刷新**（越刷越贵）、能**锁**（锁住的下一波还在）；下面是原来的「服务」（修复、增益、重摇……）。键盘 1-4 买货架、5-9 买服务、R 刷新。
  道具上限是探针逼出来的：不封顶的话倍率乘起来滚雪球，精英多、废钢多的高档位反而更好打。
- **同类套装**：带的远程 / 近战 / 炼金按把数算（重复的也算），2 / 4 / 6 把这一类伤害 +10% / +25% / +45%；近战另外缩冲刺冷却，炼金另外拉长区域。
- **属性页**：暂停里多一页「属性」，摆出真数 —— 生命、移速、伤害 / 射速倍率、暴击、免伤、每一把枪乘完品阶和套装之后的伤害和射速，三类套装到了哪一档、还差几把。
- **武器栏是全自动的**：每一把各自冷却、各自在射程里找最近的敌人 —— 刀只砍贴脸的、磁轨打远处排队的、会飞的打提前量、炼金弹直接扔到人身上。
  人只管走位和冲刺。原来是「三槽各一把、同时只开手上那一把、鼠标瞄准、`Q` / 数字键切枪」，一边躲一边切一边瞄，手机上尤其吃力，带着的另外两把一直闲着。
  火力翻了几倍之后，难度不是靠加血量追回来的（那只会让每一波更长，探针里好几局 45 分钟还没打完），而是**敌人伤害随波次涨**（第 30 波 ×1.75）：
  探针平均从全自动刚上时的 26.8 波（5 局撤离 4 局）拉回 22.0 波（撤离 2 局），跟改之前那条曲线差不多。
- **经验是带尾迹的核心，敌人子弹是转着的菱形**，粉色十字是治疗包；磁力范围内自动吸附，掉落 2.5 秒后也会缓慢向你飘。
- **升级三选一**，23 条改装词条可叠加，后期才铺开的几条改的是机制不是数值：折返弹、蓄能枪机、拆解标记、回收协议、护航无人机。
- **局内经济**：敌人掉废钢，波间开一次回收站 —— 现场修复、注入强化、多一次重摇、军械调拨（直接买一把已解锁的枪）。
  只卖消耗品和内容，不卖永久数值。没花完的存进档案，所以「现在买」和「留到下一局」是个真选择。
- **连杀 Combo** 提升得分倍率，受伤清零。
- **四档危险等级**，打穿一次解锁下一档，各存一条记录；高档位分数也更高。
  每一档还加敌人伤害（高危 ×1.6 / 熔毁 ×2.25 / 归零 ×2.3），第 6 波起渐进、第 20 波满 —— 开局一样，后半段才分出档来。
  这是武器栏全自动、加货架之后补的。探针（全解锁档案，10 局）撤离：标准 5/5、高危 5/10、熔毁 4/10、归零 2/10；平均波次 30 / 28 / 22 / 17。
- **道具外显**：每条词条在人物身上都有对应的一件东西，每把枪一个枪型。空手和拿满是两个样子。
- **换枪连人一起变**：霰弹挂胸前弹带、磁轨背电容塔、电弧肩上电极叉、榴弹腰间弹挂、振动刀背刀鞘、熔切背散热鳍、布雷器腰侧雷囊、回旋刃背环刃架。
- **涂装**：六套，纯外观不带数值，里程碑解锁；每日局用当天主题。改的是**轮廓**不只是颜色 —— 母体长角、磁轨顶环、废钢支天线、霓虹戴灯冠、幽灵罩兜帽。
- **每日局**：种子取当天日期，全世界今天同一局，固定配置、词条全开。
- **义体档案**：里程碑解锁武器与词条，废钢买起手武器，三个底座各带代价。开局只有脉冲步枪和基础词条，其余都要打出来。
- **据点**：精炼炉把废钢炼成精炼钢，装配台给每把枪装改装件（都是交换不是升级），
  捡回来的零件在这里摆摊卖 —— 有心理价位带、有客人、有名声。
  **开门营业是演出来的**：客人一个个走到摊前，头顶显示他看的是哪种零件和成交与否，
  成交就飞一枚废钢回摊位，钱一笔笔进账。点一下画面可以跳过。做够生意能养一只宠物，三只都只管经营。

## 五种属性：把散落的效果收进一套

| | 效果 | 谁给的 |
| --- | --- | --- |
| **嬗** | 打死的算在金雾里死 —— 掉双倍废钢和零件 | 嬗变之尘 / 嬗变之刺 |
| **熔** | 命中附带灼烧，三秒里持续掉血 | 熔金池 / 熔金道 |
| **引** | 弹道被拽向核心 —— 等于替你修正准头 | 引力核 / 斥力环 |
| **霜** | 层层挂霜，叠满三层**冻住一秒** | 冷凝弹头（词条） |
| **雷** | 伤害向旁边再跳一次 —— 人越挤越疼 | 电弧链 / 静电场 |

后两种不是新武器，是**把本来就有的效果收进同一套**：冷凝弹头、电弧链、静电场
原来各做各的，玩家看不出它们是一类东西。

**霜还补了一个真空白**：这游戏原来所有的控制都是百分比减速
（`slowT` 出现 9 次，`freeze` 0 次），刀锋犬的冲刺、拆解臂的蓄力撞一旦起手就打断不了。
冻结是第一个能打断起手动作的东西。冻着的时候再打不会续冻 —— 否则就是永久锁死。

**子弹穿过自己的炼金区域会被附上那块地的属性**，所以「先摆一块地，再往里面打」
是一个随时可用的组合 —— 远程槽永远不空。

### 属性反应：凑哪两种是构筑决定

两种属性落在**同一个敌人**身上会撞出第三样东西。不分先来后到，另一种已经在它身上就行：

| 反应 | 配方 | 后果 | 打什么 |
| --- | --- | --- | --- |
| **碎裂** | 熔 + 霜 | 一下 `12 + 伤害×1.5`，灼烧和霜都清掉 | 单个硬的 |
| **爆燃** | 熔 + 雷 | 就地炸 30px（`8 + 伤害×0.8`），把火传给旁边的 | 一小堆 |
| **超载** | 雷 + 引 | 56px 一圈都挨电（`6 + 伤害×0.6`） | 被引力核拽成的一大堆 |

- 「身上带着」怎么算：熔 = 烧着或站在熔金里；霜 = 有霜层或冻着；雷、引没有常驻状态，挨一下记 0.6 / 0.4 秒。
- **嬗不参与** —— 它管掉落，掺进伤害里就不是它了。
- 每个敌人反应完歇 0.8 秒。爆燃点着的邻居额外歇 0.4 秒，不然同一道电弧跳过去就当场连环爆。
- 一局里每种反应第一次撞出来会弹一条提示；暂停的构筑页列出这一局各撞了几次。

## 十七把武器 · 三条路：远程 / 近战 / 炼金

开局只有一把（脉冲步枪，或者档案里买成起手的那把）。其余十六把作为**换装卡**出现在升级三选一里（一部分要先在档案里解锁），拿到就加进武器栏，
六格以内同时自动开火。下面「三条路」的分类还在，但已经不是「每类只能带一把」了。

| 武器 | 手感 | 强在哪 | 弱在哪 |
| --- | --- | --- | --- |
| 脉冲步枪 | 中速单发 | 没有短板 | 也没有长处 |
| 霰弹枪 | 一次七发扇形，**有后坐** | 贴脸撕开一片 | 远了什么都打不到 |
| 磁轨枪 | 一条光束，**穿透整条线上所有敌人** | 他们排队的时候 | 慢，要预判 |
| 电弧链 | **自动跳**到最近的敌人，连锁三次 | 不用瞄，群战 | 伤害低，对单体差 |
| 榴弹 | 抛射落地爆炸，**能越过前排** | 成堆的时候 | 站太近会炸到自己 |
| 振动刀 | **近战**：身前扇形一刀砍一片，击退 + 回血 | 贴身、人堆里 | 你得贴上去，而敌人碰到就伤你 |

### 三把近战：各解一个近战自己的难题

近战的死因从来不是打不动，是**够不着的远程** —— 哨戒无人机停在 92px、钉枪手最远 220px。
三把各给一个答案：

| | 答的是什么 | 代价 |
| --- | --- | --- |
| **振动刀** | 人堆里怎么活 —— 扇形砍一片、击退腾空间、命中回血 | 够不着远程 |
| **冲锋撞角** | 怎么贴上去 —— 冲刺 118px 越过无人机那条线，冲的那一下无敌 | 方向按下就改不了 |
| **力场盾** | 走过去的路上怎么不被打死 —— 正面 100° 的子弹直接弹开 | 不回血，挡不住撞上来的人 |

探针实测（八个种子，强制只用这一把打满全程）：脉冲步枪 18.3 波、冲锋撞角 21.1、
振动刀 13.8、力场盾 10.6。力场盾偏低的那一截是它没有回血，
而盾的价值机器人量不准 —— 它只会瞄最近的，不会为了挡弹调朝向。

近战在这个类型里有个真问题：**敌人是靠碰撞伤人的，而近战要求你贴上去**。
所以它不能只是"射程为 0 的枪"，得自带贴上去的理由。三条补偿写进武器本身：

- **一刀砍一片**（cleave）：身前 110° 扇形、半径 42，扇形里的全砍到
- **命中击退**：把敌人推开 12px —— 这是核心，它自己把近战需要的空间打出来
- **命中回一点血**：奖励你留在人堆里；但每刀回血有上限，砍到六个也只回 3 血，
  不能就地满血

一刀左一刀右交替，挥出去有一道看得见的弧从一侧扫到另一侧。
解锁条件是**近身拆掉 8 台重装机甲** —— 机甲慢、血厚，只能贴上去打，
所以解锁本身就是一次近战预演。

**两条对刀本来是废卡的词条被改了说法**，不然拿到就等于跳过一次升级：

| 词条 | 对枪 | 对刀 |
| --- | --- | --- |
| 双联发射 | 弹丸 +1 | **扇形加宽 18°** |
| 穿甲钨芯 | 多穿透 1 个 | **砍得更远 6px** |

> 击退这里踩过一次：一开始写的是 `击退力 / 距离`，验收也过了 ——
> 但打印出来才发现只推了 2px，**等于没有击退**。
> 除以距离在贴身时会退化成零，而近战恰恰是贴着打的。
> 改成「单位向量 × 固定像素」，并把断言从「推开了」改成「至少推 6px」，
> 又补了一条「贴身砍也推得动」。**断言写成"变了"是不够的，得写成"变了多少"。**

**词条作用在倍率上，不直接改武器数值。** 这一条很重要：射速、伤害、弹丸数、
弹速那几条词条改的是 `P.mul.*`，换枪时重新用「武器基础值 × 倍率」算一遍。
不这么做的话，换一次枪就把攒了十级的强化清掉了。

## 标题页：只常驻「这一局打什么」

原来标题页一屏铺开十七把起手武器（新档里一多半是灰的「未解锁」）、三种底座、六套涂装、三组观感设置 —— 全是按钮，
手机上开始按钮被挤出首屏。现在：

- 常驻的只有**模式**、**危险档**、一行战绩、「下一个解锁」和开始按钮
- **配装**（起手 / 底座 / 涂装）收成一个折叠，按钮上直接写着现在配的是什么（「脉冲步枪 · 标准型 · 神经索」）；
  没解锁的枪不再摆成灰按钮，只写一句「另有 N 把未解锁」；买不起时自动展开，好让那句原因看得见
- **观感**（震屏 / 辉光 / 音量）也收起来
- 每日局 / 每周挑战的配装是固定的，那颗按钮直接写明、点不开

## HUD：两块面板，各自贴角

原来 HUD 是两行流式排版，数字一变长就换行 —— 竖着拿手机时量到过增益条压住废钢、WAVE 压住血条、武器框钻到暂停键底下。
现在是两块绝对定位的面板：

- **左上，自己的状态**：定宽的血条 + 数字（低于三成会闪）、等级 + 经验条 + 冲刺格、**武器栏六格**（两字简称、染武器本色，底下一条是冷却，空格画虚线 —— 还能带几把一眼看得出）
- **右上，这一局的进度**：一根窄柱 —— WAVE 和剩几只、波次进度条、分数、废钢。窄到 360 宽的竖屏也能跟左边那块并排
- 手机上暂停 / 音乐两个圆键挪到右上角，右边那块排在它们下面；增益条、连击数各自排在两块下面
- 波次 / 敌人提示的横幅从 38% 挪到 22% —— 原来正压在玩家头上（人永远在画面正中）

验收里守的是几何约束（两块绝对定位、标签紧跟数字、右边那块在圆键下面），真正的重叠是在浏览器里量四种屏幕（桌面、横屏、390 竖屏、360 竖屏）的包围盒，全部零重叠。

## 武器特效：先上屏，再谈好看

被说过「武器和子弹效果看不太出来」。查下来一半是 bug：**挥砍弧、光束、电弧画在 `update()` 里**，
而 `render()` 一上来就把整块画布涂成背景色 —— 磁轨、熔切光束、电弧链、雷跳、近战的挥击弧，
从加进来那天起就没上过屏幕。挪进 `render()`（`drawStrikes`），验收里加了一条「update 里一笔都不画」守着。

另一半是尺寸：画面只有 320×180，原来子弹的尾巴是「上一帧到这一帧」那一段（一帧 4px）加 1px 白芯，
开枪只有几颗 1px 火星，命中只有 1~2px 碎屑。现在：

- **子弹**拖按速度算的固定尾巴（6~14px），三层：外光、本色、白芯；暴击粗一号、金色
- **开枪**枪口闪一下（武器本色），**命中**在打中的地方闪一下 —— 都只活六七十毫秒
- **榴弹 / 炼金弹**是抛出去的：地上有影子，球沿弧线飞，读得出「越过前排落下去」
- **光束**三层；熔切光束按住时不淡出、尽头在抖，像在烧
- **电弧**每个落点亮一下；**回旋刃**、**地雷**放大一圈

满屏 64 只怪、霰弹连射，帧时间跟改之前一样（16.7ms，锁在 60 帧）。

## 人物与怪物：先分轮廓，再谈细节

原来五个单位都是「圆角方块加个亮心」，在一群怪里只能靠颜色区分，靠不了轮廓。
重画之后每个的剪影都不一样：

| 单位 | 剪影 | 会动的地方 |
| --- | --- | --- |
| 玩家 | 朝镜头的护盔人形，枪跟着准心转 | 四帧走路，脚交替 |
| 拾荒机兵 | 带四条短腿的方箱 | 腿交替 |
| 刀锋犬 | 又低又长的水滴，前端一把刀 | 冲刺时刀锋伸出 |
| 哨戒无人机 | 菱形本体 + 四个角上的旋翼 | 旋翼三帧转 |
| 重装机甲 | 上下两条履带的宽板 + 肩炮 | 履带滚动 |

地面单位有投影，无人机有悬浮起伏 —— 这两样让它们看起来是"踩在地上"和"飘在空中"，
而不是都贴在同一个平面上。

**辉光只让亮的部分参与了。** 原来是整帧下采样再加回去，等于把中间调也一起点亮，
新精灵的细节全被糊平。改成先提亮度加对比度近似一个阈值，霓虹还在发光，像素也看得清。

## 验收

```bash
npm run check:neon
```

游戏整个包在 IIFE 里，`node --check` 只能查语法，查不出**初始化顺序**这类错。
`tools/verify-neon.js` 用一个最小 DOM 桩把整段脚本真的跑一遍，再逐条检查：
精灵每行宽度、武器表字段、换枪不清词条、每把枪各自的产物（几发子弹 / 一条光束 /
一条折线 / 一枚抛射物 / 一颗雷 / 一片回旋刃）、经营层不许出数值、屏幕上分不分得清。
桩的画布可以打开录制（`ctx.__rec()`），所以"画出来长什么样"也能断言 ——
「跟班像掉落物」这类 bug 在数据层全是对的，只有画面能证伪。

> 加这个脚本是因为踩了一次：词条表里引用了还没声明的武器表，
> 浏览器里的表现是「标题页正常，点开始没反应」，控制台什么都不报。

## 人物：身体朝镜头，道具挂在身上

以撒和土豆兄弟的人物之所以看得清、之所以挂得住道具，是因为**身体始终朝着镜头**。

原来这里的人物随准心整体旋转 —— 俯视角的人必然是个圆块：没有头、没有手、没有脚，
也**没有固定的地方能挂东西**。所以换了画法：

- **身体朝镜头**，16×20，四帧走路循环（护盔、面罩、肩甲、两条腿交替）。往左瞄就水平翻转。
- **只有枪跟着准心转**，绕胸口一个支点。朝左时上下翻一次，否则枪会倒过来。
- **枪型按武器换**：每把枪一个形状（细管 / 双管 / 带线圈 / 叉状电极 / 粗口 / 聚焦镜 / 投掷筒 / 环刃架）。

### 升级了，身上就多一件

每一条能叠的词条都对应一片贴花，挂在固定槽位，分三层：

| 层 | 挂什么 |
| --- | --- |
| 枪上（跟着枪转） | 散热片、冷凝罐、配重、长针、制退器、环形透镜 |
| 背后（被身体压住一半） | 药罐、爆裂罐、电容组 |
| 身上 | 头侧目镜、头顶残影环、肩上输血管、左肩盾板、腰间磁环、腰侧电极、腿侧助推、脚后尾翼 |

**双联发射走的不是贴花，是真的多一根枪管** —— 叠两层就是三根管，这是最看得出来的叠加。

空手 → 拿六条词条 → 拿满，人物是明显不同的三个样子。
贴花只用调色板键，所以**跟着涂装一起换色**，不用为六套涂装各画一遍。

> 验收里有一条守着这件事：**每一条能叠的词条都必须有对应外显**，
> 少一条就红。否则以后加词条很容易忘了给它画东西，
> 而"升级了看不出变化"正是这次要解决的问题。
> 另有一条查贴花不许挤在同一个槽位 —— 挤在一起会糊成一团。

> 顺带一个手感上的取舍：人物现在 16×20，比受击半径（7px）大不少，
> 尤其纵向。这是刻意的宽容方向 —— 子弹擦着头顶和脚边过去不算命中。

## 怪：也朝镜头站着

人物改成正面之后，怪还是俯视的方块精灵、整张图跟着朝向转 —— 转起来就是一块几何体，
跟正面站着的主角也不在一个世界里。所以怪也换成同一个画法：

| 怪 | 造型 |
| --- | --- |
| 拾荒机兵 | 锈色小个子，一只红独眼，拎一截钢管 |
| 刀锋犬 | 侧面的四足机械狗，背上一排刀片；冲刺时往前扑、身后拖速度线 |
| 哨戒无人机 | 紫色眼球机，顶上两副旋翼在转，底下一根枪管 |
| 重装机甲 | 宽肩双足机甲，橙色观察窗；后肩扛炮，开火前炮口先亮 |
| 铁闸 | 驼背的灰色重步兵，手里一块盾 |
| 爆囊 | 长了脚的红炸弹，头顶引线 |
| 信号中继 | 三脚架上的小塔，顶上天线碟，绿芯一闪一闪 |
| 裂解体 / 裂片 | 一团会蠕动的绿色胶质，裹着暗核；裂片是一小团 |
| 钉枪手 | 瘦高的紫斗篷，兜帽下一条红光，手里一杆长枪 |
| 拖曳者 | 粉色蟹形机，一只大钳子，钩索从钳子里甩出去 |

- **左右翻身代替整图旋转**，带一点迟滞：怪在正上 / 正下方时不会每帧来回翻。
- **脚踩在投影上**（图的底边对齐受击圈的下沿），飞的悬在正中。
- 站着不动就停在第一帧；旋翼、胶质、天线、引线这些站着也在动。挨打时压扁一下。
- **有方向的部件单独画、自己转**：铁闸的盾、钉枪手的枪、重装的炮。方向本身是玩法 ——
  盾挡在哪一侧、枪口指着谁 —— 整图不转之后这些信息不能跟着丢。
- 怪用的是**一组小写字母的调色板**。涂装只重映射 B/S/L/C/O/H 六个大写字母，
  原来的怪用了 S/L/O，换涂装会把怪也一起染了；现在不会。验收里守着这条。

BOSS 没动：它们本来就是大块的机械，自转本身就是招式的预告。

## 地上的东西：看得出是干什么的

原来六种增益都是「一个转着的方框」，只靠颜色分；头顶的标签只写名字（超频、护壁、电容组）——
名字是游戏里的造词，看不出捡了有什么用。

- **每种增益一个图标，画的就是效果**：闪电 = 射速×2、盾 = 无敌、磁铁 = 吸经验、爆星 = 炸一圈、沙漏 = 敌人减速、心 = 杀怪回血。
- **标签写「名字 · 用处」**：`超频 · 射速×2`、`伺服马达 · 回据点卖钱`。捡到时的横幅也写清楚多少秒、干什么。
- 货架和服务的说明改成大白话：「整合度」→「血」、「身周放电 +3」→「身边电场：贴身的怪持续挨电」、暴击写明打 3 倍。
  卡片宽度有限，说明都压在一行内，不然服务区会被撑高、把「下一波」挤出屏幕。

## 据点：一条能点的街

据点原来是三栏文字卡片，盖了精炼炉就是表里一行变绿 —— 花了几千废钢，看不见它「长」了。
现在据点本身就是一条赛博街（400×170 的像素画，按整数倍放大）：

- **九处一字排开**：精炼炉、装配台、弹药库、宠物窝、货摊、委托板、工坊、义体车间、情报站。
  每栋都是程序画的像素建筑：精炼炉的炉膛在闪、烟囱冒烟（一级一根），装配台的机械臂在焊（一级一副），
  弹药库门口的箱子越堆越多，情报站的碟子在转（一级一只），义体车间的十字招牌一级会闪、二级常亮。
- **没盖的是工地**：围栏、一块「+」牌子，上面淡淡地画着盖好以后的样子。
- **活的**：雨、远处的楼窗明灭、高架上过车、全息广告牌闪；霓虹在湿马路上有倒影。
  宠物在街上溜达，名声越高路过的客人越多；炼好的精炼钢码在精炼炉门口，做好的随身物摆在工坊架子上，
  委托板上钉着三张单子、凑齐的那张发绿光；开门接客时客人就站在货摊前，头顶一个问号。
- **点一栋楼，下面只出它那一块**。楼头上的「!」（有事：有货能卖、委托能交、能做东西）和「↑」（买得起下一级）
  替代了原来那排五格步骤条 —— 只留一句「下一步」，点它直接选中该去的那栋。
- 钱和「返回」钉在最上面。手机上街比屏幕宽，横着滑，进来时自动滚到选中的那栋。

## 据点：打完回来有事可想

原来据点就是「定个价、点开门、买几栋楼」，打完一局回来没什么要动脑的。加了四样：

| | 干什么 | 为什么 |
| --- | --- | --- |
| **委托** | 三张订单，「带回 4 个光学镜组，给 2 倍价 + 1 精炼钢」，限 3 局。凑齐了点一下交货 | 把据点和战斗串起来：下一局知道该去打谁（卡上写着哪种怪掉）。局内捡到会报进度，暂停的货箱页也列着 |
| **开门接客** | 客人一位位来。出价够标价的自己买走；不够的站在摊前等你：按他的价卖 / 还价 / 请走 | 一键结算只有「标价」一个决定；现在每位客人都是一个决定。砍价客还价多半成，急客一还价就走，收藏家只要缺货的 |
| **工坊** | 零件做成随身物，下一局自动带上，一次性，最多两件：应急炸药、备用电池、寻宝镜、开局补给 | 零件多了「卖钱还是自己用」的取舍，委托又在抢同一批货。都是有触发条件的一次性东西，不卖裸数值 |

「一键卖」还留着，给不想讨价的时候用。每日局 / 每周挑战不带工坊的东西（大家同一局）。

## 涂装：只换外观

精灵是**字符网格 + 调色板索引**画出来的，不是位图：

```js
const ch = rows[y][x];          // 网格里的一个字符
t.fillStyle = pal[ch];          // 查调色板
```

所以**换一份调色板就是一套新皮肤，网格一个字都不用改**。六套涂装：

| 涂装 | 怎么解锁 |
| --- | --- |
| 神经索 | 默认 |
| 母体 | 拆掉一个母体核心 |
| 废钢 | 累计 1000 废钢 |
| 磁轨 | 活到第 12 波 |
| 霓虹 | 累计拆解 1500 个 |
| 幽灵 | 打满 20 局 |

换涂装同时换掉冲刺拖尾、护盾环、身周光圈和小地图上的自己 —— 一处配色贯穿到底。
每套烤一份精灵缓存住，之后换涂装是零成本。

**每日局用「今日主题」涂装**（种子取当天日期），而且不看解锁 ——
外观不影响公平，没道理拦着。

### 刻意不带数值

涂装不附带任何效果。带了它就成了第二套底座系统，跟已有的底座打架，
而且会把「选好看的」变成「选强的」。

这一条不是靠自觉，是**被测试守着的**：`tools/verify-neon.js` 里有两条断言 ——
换遍六套涂装开局，玩家的 17 个数值字段必须完全一致；
以及涂装的定义里不许出现任何生效函数（结构上就没法带数值）。

> 顺带一句：加涂装的时候，那条「所有里程碑给的都是新东西，不是永久数值加成」的
> 元断言直接红了 —— 因为它只认「卡池 / 词条 / 底座」三种奖励。
> 这正是它该做的事：**逼我明确把「涂装」加成第四种奖励类型，而不是偷偷混进去。**

## 逼你改打法的敌人：先加的三种

原来五种敌人只在血量和速度上不同，**应对方式全是「对着打」**——
所以武器的差异是存在的，但没有敌人来考它。先加了这三种来考它
（后来又加了裂解体、钉枪手、拖曳者，现在 11 种里有 6 种属于这一类）：

| 敌人 | 机制 | 逼你做什么 | 谁是答案 |
| --- | --- | --- | --- |
| **铁闸** | 正面 ±65° 只吃 15% 伤害，转身慢 | 绕到它侧后方 | 任何武器 + 走位；**或者榴弹** |
| **爆囊** | 靠近 30px 点火，0.55 秒后炸，连锁伤敌 | 远距离点掉，别贴着 | 远程；**振动刀在这里是短板** |
| **信号中继** | 给 78px 内的敌人减 65% 伤害，画连线 | 先打谁后打谁 | 电弧链自动跳、磁轨穿透一整排 |

**爆炸无视盾**，这不是特例，是从实现里自然掉出来的：`hurtMob` 只有带来源坐标时才判方向，
而爆炸不传来源。所以榴弹和「爆裂核心」词条天然是铁闸的答案 —— 一个规则，两个后果。

**中继的连线是关键的界面**。被护着的敌人套一层绿环，中继和它护着的每一个之间画一条线，
所以"为什么打不动"和"该先打谁"不用文字解释。中继一死，护盾在几帧内自己掉 —— 不是永久的。

> 盾的方向我第一次写反了：`rel > 115°` 挡的是**背后**。
> 验收里那条「正面打只进多少伤害」当场就红了（正面 100、背后 15，正好倒过来）。
> 这类方向错误看代码很难看出来，**必须写成两个方向都量一遍的断言**。

## 观感设置（可及性，不是打磨）

震屏最高到 10、辉光叠两层，这对晕动敏感的人是硬门槛，而原来**没有关的办法**。
标题页的档案面板上加了一行：

- **震屏** 关 / 弱 / 标准
- **辉光** 关 / 开（关掉时整段后处理都跳过，不是只把透明度调 0）
- **音量** 静音 / 低 / 标准

系统里开了「减少动态效果」时，**震屏和辉光默认就是关的**，不用用户自己去找，
面板上也会说明一句。三项都存在档案里。

## 场地：打赢一个 BOSS 就换个地方

三张场地轮转，**形状不一样才是重点**，不只是换个颜色：

| 场地 | 尺寸 | 打起来的区别 |
| --- | --- | --- |
| 废钢回收线 | 1216 × 768 | 标准，横向跑得开 |
| 熔渣池 | 1024 × 1024 | 方的，横向没那么多逃跑余地，纵向多 |
| 冷却塔 | 1440 × 608 | 又扁又长，视线远 —— 磁轨枪的主场 |

BOSS 在第 5 / 10 / 15 / 20 / 25 波，所以第 6 / 11 / 16 / 21 / 26 波换场地：**打赢了就往前走**。去哪一张由打完 BOSS 时的选路决定（见上面「打完 BOSS 选路」）。
换场地时清掉残留的敌人和子弹，把人放到新场地中间（不然会卡在墙外）。
装饰色和网格色跟着场地变。

## BOSS：两个形态

原来 BOSS 是程序化画的几个旋转六边形，和四种杂兵重画之后**画风是断的**。
现在它走精灵，两套：

- **第一形态**：外层装甲板完整，核心小而暗，十向环形弹幕，偶尔召唤
- **掉到一半血 → 外壳崩解**（屏幕震一下，横幅提示）
- **第二形态**：**一半装甲板没了、核心露出来发白**，速度 ×1.5，
  弹幕从「一波一波的十向」改成**连绵不断的螺旋**，召唤刀锋犬

改的是打法，不是血量。一个只是血更厚的第二形态不值得做。

## 手机上能暂停了

触屏原来只有「冲刺」和「枪」，`P` 和 `M` 是键盘专用的 —— **手机玩家中途没法停**。
右上角加了「暂停 / 音乐」两个键。

> 这里有个坑：触屏层原来的显示条件是「play 且没暂停」，
> 所以一暂停，**连暂停键自己都消失了，再也点不回来**。
> 改成暂停时只收起摇杆和动作键，系统键留着。
> 顺带发现画布上那行暂停提示写着「按 P 继续」—— 手机上没有 P 键，改成分设备显示。

## 每日局：全世界今天同一局

标题页上可以切「自由 / 每日」。每日局的种子取当天日期，所以**同一天所有人面对的是
同一批怪、同一批三选一**，比的是谁玩得好。今日成绩单独存，不和自由局的历史最好混。

**每日局是固定配置**：标准底座、脉冲步枪、**全部词条开放**。
如果让档案生效，解锁多的人天然占便宜，"在同一条起跑线上比"就不成立了。
顺带一个好处：每日局是新手唯一能立刻见到全部内容的地方。

### 武器进化：一把枪 + 一条词条叠满

叠满跟这把枪对路的那条词条，**下一次升级必出它的进化**（金边牌，顶掉第三张；不多摇牌，每日局牌序不变）。
进化不加数值，让这把枪自己带上一种属性 —— 所以它跟属性反应是一套东西：

| 进化 | 条件 | 改了什么 |
| --- | --- | --- |
| 霜脉冲 | 脉冲步枪 + 穿甲钨芯叠满 | 子弹自带霜，命中叠一层（子弹变成冰白色） |
| 龙息 | 霰弹枪 + 双联发射叠满 | 每一颗弹丸自带熔，命中点燃三秒 |
| 雷暴链 | 电弧链 + 静电场叠满 | 多跳三下，每跳把 40px 内的人拽过来并挂上引 —— 自己就能撞出超载 |

进化不进词条表（`EVOS` 单独一张），「23 条改装词条」这个数不变。暂停的构筑页有一行「进化」。

### 每周挑战：同一局，外加一条规则

标题页的模式多了「每周」。它跟每日局走同一套固定配置（标准档、词条全开、据点不生效），
种子取这一周（周一到周日），外加一条**改打法**的规则，四条按周轮换：

| 规则 | 改了什么 |
| --- | --- |
| 只准近战 | 开局拿振动刀，远程枪不进卡池 |
| 没有冲刺 | 相位冲刺拆掉（商店的「整备」也充不上） |
| 玻璃义体 | 生命上限只有四成，伤害 ×1.6 |
| 急行军 | 敌人快 25%，经验多三成 |

本周成绩单独存（`ns.weekly`），不碰自由局和每日局的记录；上周的挑战存档不给续。

### 随机源分了三条流

仓库的规矩是不用 `Math.random`（市井那边写在文档里）。这次补上了 ——
整份文件现在零处引用。但真正要紧的不是换掉它，而是**分流**：

| 流 | 管什么 | 为什么单独一条 |
| --- | --- | --- |
| `RNG.wave` | 刷怪表、掉落、场景装饰 | 每日局要保证同一批怪 |
| `RNG.card` | 升级三选一 | 每日局要保证同一批卡 |
| `RNG.fx` | 粒子、暴击、护盾 | 不影响公平，随便摸 |

混在一条流里的话，**你多打一发子弹，下一次三选一的三张卡就变了** ——
那"大家一样"就不成立了。验收里专门有一条：粒子流摸 500 次，卡牌流必须还是同样三张。

> 每日局保证的是**刷怪表和三选一完全一致**，不保证逐帧一致 ——
> 敌人的行为会随你的走位分岔，这是动作游戏的每日局都有的性质。

## 成长：义体档案

Roguelite 的成长系统最容易做坏的一点是**给永久数值加成** —— 那只会让前期变简单，
把已经通过的关卡再削一遍，玩得越久越无聊。

所以这里三层，没有一条是纯数值：

### ① 解锁：改变「可能出现什么」

九个里程碑，达成一次永久解锁一样东西。**开局只有脉冲步枪，卡池只有 15 张基础词条**，
四把枪和三张带代价的词条都要打出来：

| 里程碑 | 解锁 |
| --- | --- |
| 活到第 4 波 | 霰弹枪进卡池 |
| 活到第 6 波 | 底座：轻甲型 |
| 活到第 7 波 | 磁轨枪进卡池 |
| 累计拆解 400 个 | 电弧链进卡池 |
| 打满 5 局 | 新词条：过载电容（射速 +45%，生命上限 -15） |
| 活到第 10 波 | 榴弹进卡池 |
| 拆掉 20 台重装机甲 | 新词条：反冲抑制（散布 -60%，弹速 +40%） |
| 累计 600 废钢 | 底座：重载型 |
| 拆掉一个母体核心 | 新词条：幽灵协议（冲刺 CD -50%，生命上限 -20） |

**每一局都在扩大未来局的可能性** —— 这才是「下一局会不一样」。
三张新词条全都带代价，纯加强的卡不会被记住。

### ② 废钢：改变「怎么开局」

每局产出 `波次 × 12 + 击杀`，所以**打崩的一局也不算白打**。
攒 150 废钢把某把已解锁的枪买成起手武器，下一局就从它开始。

### ③ 底座：改变「这一局的性格」

三个底座都带代价，选的是想怎么打，不是哪个更强：

| 底座 | 效果 |
| --- | --- |
| 标准型 | 没有加成，也没有代价 |
| 轻甲型 | 移速 +25%，生命上限 -30 |
| 重载型 | 生命上限 +60，移速 -15% |

档案面板就在标题页上，不另开一屏：废钢 / 局数 / 累计拆解、起手武器、底座、
以及一行「下一个解锁：活到第 10 波 → 榴弹进卡池」。
死亡屏上会写这一局挣了多少废钢、解锁了什么。

> **读档时会补发早该给的里程碑。** 条件满足和奖励发放是两件事：奖励只在一局结束时结算，
> 所以直接改档案或者新版本加了里程碑，都会出现「条件早过了但没发」。
> 进游戏先补一次，否则面板上会写着「打满 5 局」而你已经打了 11 局。

## 一局打完留下什么

Roguelite 的勾子只有一句话：**下一局会不一样**。而一局打完如果什么都不留下，
"我死了"就只是一个会被忘掉的数字。所以死亡屏上现在有三行：

```
义体在第 9 波被重装机甲拆解
打法：磁轨枪 + 超频枪机 + 穿甲钨芯
最好：第 12 波 —— 差 3 波
```

- **被谁拆的**。伤害来源一路带到 `hurtPlayer(dmg, src)`，敌人子弹也带着发射者的类型。
  「被刀锋犬拆的」和「被自己的榴弹炸死」是两种完全不同的教训。
- **这局是什么打法**。打出伤害最多的那把枪 + 堆得最多的两条词条。
  换装卡不算进"堆"出来的词条里 —— 它不是堆出来的。
  一局有了名字，才会想再来一局证明另一套。
- **离最好差多少**。先比波次，波次一样比分数。
  这一条把"我死了"变成"我差三波"，是所有改动里回报最高的。

最好成绩存在 `localStorage['ns.best']`，连那一局的打法一起存 ——
所以标题页上写的是「最好：第 12 波 · 21400 分 · 磁轨枪 + 穿甲钨芯 + 暴击回路」，
你一开局就看见要打败的是什么。读写都包了 try/catch：**无痕模式下 `localStorage`
会直接抛异常**，不能让存档把游戏带崩。

> 另一半勾子「解锁改变开局」后来做成了义体档案（里程碑解锁武器 / 词条 / 底座，废钢买起手武器），见上面一节。
> 那是让"下一局会不一样"真正成立的东西，但要先定解锁什么，是个设计决定。

## 手机上怎么玩

双摇杆射击在手机上有一套约定俗成的做法，照着来：

| 操作 | 做法 |
| --- | --- |
| 移动 | **左半屏任意位置按下**，摇杆的圆心就落在你按下的那一点 |
| 瞄准 | **右半屏按下并拖**，按着就一直开火 |
| 不瞄 | 右手不按时**自动瞄最近的敌人并开火** —— 单手也能玩 |
| 冲刺 / 换枪 | 右下角两个按钮 |

摇杆的圆心跟着手指落点走，不是固定在屏幕角上 —— 固定的话拇指每次都得先去找它。
两个摇杆各自记住自己的 `pointerId`，所以能同时用。

**触屏层盖的是整个视口，不是画布。** 竖屏时 16:9 的画布只占屏幕中间一条，
而拇指是放在屏幕最下面的 —— 只盖画布的话，手指按在画布外面就什么都不会发生。
横过来玩视野宽一倍，竖屏时顶上会有一行提示。

**触屏模式是第一次真的碰到屏幕时才切的**，不是开局用 `pointer: coarse` 猜一次。
触屏笔记本插着鼠标时指针是 fine，但用户照样会用手指戳屏幕；反过来，
猜错了就永久失效。监听器一直装着，碰到屏幕那一刻再切。

顺带处理的几件小事：禁掉双指缩放和双击放大（玩着会被放大）、
关掉下拉刷新和橡皮筋、按钮避开刘海和小白条、切后台自动松开摇杆
（否则回来还在"按着"）、横竖屏切换和地址栏收起都重算画布尺寸。

## 想自己调参

全部数值集中在本目录 `index.html` 的这几个位置，直接改数字即可：

| 位置 | 作用 |
| --- | --- |
| `const VW / VH` | 内部渲染分辨率（越小像素越大） |
| `const ARENA` | 场地尺寸 |
| `const BASE` | 玩家初始属性（速度、射速、伤害、拾取范围…） |
| `MILES` / `CHASSIS` / `WEP_COST` | 里程碑、底座、买起手武器的价钱 |
| `SKINS` | 涂装（只是调色板覆盖，改它不会影响玩法） |
| `RNG` / `seedRun` | 三条随机流；改了会影响每日局的可复现性 |
| `const MOB` | 各类敌人血量 / 速度 / 伤害 / 经验 |
| `const UPGRADES` | 词条名称、描述、效果函数、叠加上限 |
| `nextWave()` / `waveSpawn()` | 波次时长、刷怪预算与刷怪表 |
| `hpS / spdS` in `spawn()` | 难度随波次的成长曲线 |

渲染管线：低分辨率 Canvas → 两级降采样叠加做辉光（bloom）→ 预渲染扫描线 + 暗角 → 移动扫描带。想更"干净"就把 bloom 的 `globalAlpha` 调低。

## 兼容性

Chrome / Edge / Safari / Firefox 桌面端与手机均可运行。桌面用键盘鼠标，手机用双摇杆（见上面一节）。
音频在首次点击或触摸后才会初始化（浏览器自动播放策略）。
