# 炮塔拆方块 · 灰盒原型

验证《这关消一消》那类玩法的核心循环好不好玩。没有美术、没有音效、没有特效——
只有规则。单文件，双击 `index.html` 就能玩（需要能访问 cdnjs 加载 Three.js）。

## 规则

- 中间是**浮空**的彩色 cube 立体图案，左右拖动转动它（量化成 8 个朝向）——
  **只有图案会转，相机、槽位、炮塔全都固定不动**（滚轮可以拉远拉近，那只是看，不是转）
- 下方 5 个固定槽位，货架上排着一列炮塔，**点一下货架上的炮塔就按顺序进下一个空槽位**
- 炮塔有颜色和弹药数，进槽位后按节奏自动开火，只打**同色**且**直线视线没被挡住**的 cube
- 炮塔固定在槽位里不动，图案转动会实时改变所有炮塔的视线
- **轮到开火时这个朝向没有能打的目标，这一发就打空了**
- 货架只有前 6 个能取；炮塔全部用完而方块没拆光 → 输

## 决策在哪

1. **转到哪个朝向**——这是主要动词。8 个朝向下每个炮塔能打到的数量完全不同，
   货架每张卡片右上角实时显示「放进下一个槽位、按当前朝向能打几个」
2. **同时开几个炮塔**——一个朝向不可能同时喂饱 5 个炮塔。开得越多，打空得越多
3. **拿哪个炮塔**——货架窗口只有 6 个，拿走一个就补一个新的

## 为什么「打空」必须存在（原型量出来的）

一开始我按「炮塔没目标就停着等」来做，跑蒙特卡洛发现**随机乱玩的通关率是 1.00**：
只要允许自由转动，总能转到某个角度让某个炮塔继续开火，死局在物理上不可能出现，
游戏就没有失败条件了。

所以失败条件必须来自**资源浪费**而不是卡死。加上「没目标就打空」之后：

| 弹药冗余 | 乱放乱转 | 塞满 5 个槽位 | 只开 2 个槽位 |
| --- | --- | --- | --- |
| 0%  | 0.01 | 0.21 | 0.50 |
| **15%** | **0.01** | **0.50** | **0.71** |
| 25% | 0.07 | 0.57 | 0.71 |
| 40% | 0.15 | 0.79 | 0.71 |

15% 冗余这一行是想要的形状：乱玩基本必输，控制并发数的打法明显更优。
三种策略都在 `C.playout(level, rng, 'random'|'fill'|'careful')` 里，可以自己复现。

## 技术核心：保证有解的关卡生成器

关卡不是随机堆出来的，是**正向随机解一遍再把解法记成炮塔序列**，所以底子上一定有解；
再按比例掺入弹药冗余，最后蒙特卡洛跑若干局筛掉太难和太水的。

```
node -e "const C=require('./core.js');console.log(C.makeLevel(12345).eval)"
```

### 视线判定为什么这么快

cube 只会消失、不会出现，所以**视线是单调的**：一个 cube 一旦从某个位置看得见，就永远看得见。
于是建关时一次性算出「A 挡住了哪些 B」，之后每死一个 cube 只需给受影响的 B 计数器减一，
减到 0 就推进对应的最小堆。每次开火 O(log n)。

转动图案等价于炮塔绕竖轴反向转，所以 8 个朝向 × 5 个槽位 = 40 个等效炮塔位置，
照样全部预计算。生成加验证 40 关约 1 秒。

## 手感与界面

反馈都挂在「每一发炮弹」上，因为那是重复几百次的动作：

- **命中**：炮塔后坐 + 炮口闪光 + 有厚度的加法混合弹道 + 方块先撑大再炸开 + 五片碎屑带重力飞散 + 轻微镜头抖动
- **打空**：灰色弹道穿过图案射向虚空 + 炮塔横向抖动 + 机身发红 + 右上「打空」计数器弹一下变红
- **音效全部用 WebAudio 现场合成**，没有音频文件。命中音随连击升半音，连着打会有旋律感；打空是一记闷响
- **转动**：拖动带甩动惯性，松手吸附到最近一档，每过一档有「咔」一声，右上表盘同步指示
- **进关**：方块从下往上依次弹出；**开局自动摆到「货架前六个里可用炮塔最多」的朝向**，避免一上来满屏是 0
- **放置**：炮塔从上方砸进槽位，槽位面板同步弹一下

界面上信息按重要度排：

- 左上「剩余方块」是主数字，下面一条按颜色分段的进度条，同时兼做图例——打掉一片，对应那段就缩一截
- 右上是朝向表盘（8 档刻度 + 指针）和打空计数
- 货架每张卡右上角的角标＝**放进下一个槽位、按当前朝向能打几个**，绿色有目标、红色会打空；悬停会在 3D 里用同色描边圈出它能打到的方块
- 弹药 ≤5 用点阵、>5 用数字，扫一眼就知道多少

## 已知的设计问题

- 关卡长度 30 手左右，对休闲小游戏偏长，改 `maxCubes` 可以砍到 15–20
- 没有引导关，新手不会意识到「同时开太多炮塔会疯狂打空」——第一关应该刻意教这一点
- 开火节奏固定 620ms，快慢会直接改变难度，这个值应该随关卡调
